REAL BRITAIN, AS DOOM LEVELSpostcode2wad

Every square below is 800 m of real England, generated from Environment Agency 1 m LIDAR and OpenStreetMap: real building footprints at measured heights, sloped terrain, hedges, trees. Click a square to walk it. WASD moves, mouse looks; desktop only. Dark squares are the sea.

Map data © OpenStreetMap contributors (ODbL). Terrain: © Environment Agency copyright and/or database right 2022, OGL v3. Geocoding contains OS data © Crown copyright and database right.
Engine: UZDoom via the uzdoom-wasm port, both GPLv3 — source at those links. Game assets: Freedoom (modified BSD). Each level embeds its own ATTRIBUTION.txt.
Generator: postcode2wad — type a UK postcode, get a playable GZDoom level of that real place.
